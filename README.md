# WB FBS ТСД — Складское приложение для Wildberries FBS

## 📋 Описание

Нативное Android-приложение на Kotlin + Jetpack Compose для работы с заказами Wildberries FBS на терминалах сбора данных (ТСД).

## 🎯 Ключевые улучшения UX (vs М15)

| Проблема М15 | Наше решение |
|-------------|--------------|
| ❌ Нет группировки одинаковых товаров | ✅ Группировка по артикулу+размеру: «Футболка белая L × 5» |
| ❌ Жёсткая привязка к одному заказу | ✅ Клиент → Заказы (гибкая структура) |
| ❌ Маленькие кнопки | ✅ Крупные элементы (64dp кнопки, 48dp иконки) |
| ❌ Нет прогресса сканирования | ✅ Прогресс X/Y крупным шрифтом (48sp) |
| ❌ Непонятные статусы | ✅ Цветовые индикаторы: зелёный «готов», красный «не готов» |

## 🔄 Пайплайн сборки заказов

```
📋 Заказ → 📦 Подготовка → 🔍 Проверка → 🏷️ КИЗ → ✅ Отправка
```

### Экраны приложения

1. **Заказы** — список входящих заказов (клиент, дата, товар)
2. **Подготовка** — разбор товара, артикул, размер, цвет, проверка
3. **Проверка** — сканирование каждого товара по штрихкоду/QR через камеру ТСД
4. **КИЗ** — сканирование Data Matrix кодов маркировки, прогресс X/Y
5. **Готово** — отправка в доставку, печать этикетки

## 🛠 Технологический стек

- **Язык:** Kotlin 1.9.20
- **UI:** Jetpack Compose + Material 3
- **Навигация:** Navigation Compose
- **Камера:** CameraX + ML Kit Barcode Scanning
- **HTTP:** Retrofit + OkHttp
- **Асинхронность:** Kotlin Coroutines
- **Мин. SDK:** 26 (Android 8.0)
- **Целевой SDK:** 34 (Android 14)

## 📱 Требования к устройству

- Android 8.0+ (API 26+)
- Камера для сканирования штрихкодов/Data Matrix
- Интернет для API WB FBS и Честный Знак
- Опционально: Bluetooth для внешних сканеров

## 🔌 API Интеграции (в разработке)

### Wildberries FBS API
- Получение заказов
- Обновление статусов (принять → собрать → проверить → подготовить → отправить)
- Данные о товарах (артикул, название, количество, цвет, размер)

### trueAPI ЧЗ (Честный Знак)
- Ввод КИЗ (регистрация вывода из оборота при упаковке)
- Проверка Data Matrix кодов

## 🎨 Дизайн-система

### Цвета (тёмная тема)
- Фон: `#121212`
- Поверхность: `#1E1E1E`
- Акцент зелёный: `#4CAF50` (готово)
- Акцент оранжевый: `#FF9800` (в процессе)
- Ошибка красная: `#F44336` (не готово)

### Размеры (для перчаток и больших пальцев)
- Кнопки: 64dp высота
- Иконки: 48dp
- Текст заголовков: 24sp
- Текст прогресса: 48sp (очень крупно)
- Мин. зона тапа: 48dp
